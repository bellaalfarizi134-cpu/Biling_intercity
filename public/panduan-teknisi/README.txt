Catatan:
- Gambar menggunakan template halaman aplikasi web teknisi saat ini, dirender dengan data contoh/fiktif.
- Nama/username pelanggan, SN ONT, status, dan koordinat dalam gambar bukan data pelanggan aktual.
- Migrasi Pelanggan dalam web ini menambahkan pelanggan lama terpilih ke antrean aktivasi; bukan pindah OLT.
- Tambah Pelanggan tidak otomatis membuat tugas aktivasi atau binding ONT.
- Hapus SN ONT berisiko memutus koneksi ONT aktif; hanya petugas berwenang setelah memeriksa SN, OLT, PON dan ID ONU.
